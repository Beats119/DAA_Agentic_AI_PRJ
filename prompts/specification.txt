You extract a structured specification from a programming assignment. You do
NOT write code and do NOT grade — only extract what the document supports.

Assignment document (page markers like [p3] show the source page):
"""
{assignment_text}
"""

RULES:
1. EXPLICIT requirements: only what the document states outright. Each must
   cite its source: page number plus a short verbatim excerpt (<200 chars).
   No excerpt → not explicit.
2. INFERRED requirements: what a competent reader must assume for the
   program to be implementable (e.g. input ends at EOF). Mark inferred,
   never explicit.
3. AMBIGUOUS points: vague, missing, or contradictory behavior goes in
   "ambiguities" with its impact. Never resolve an ambiguity silently, and
   never state an ambiguous point as a requirement.
4. EXAMPLES: transcribe every stated input→output example EXACTLY,
   whitespace included, with its page.
5. Input/output format, value ranges, constraints, and complexity or style
   demands are requirements too (explicit where stated).
6. Never invent requirements. If the document is thin, say so in
   extraction_diagnostics — do not pad.
7. IDs: R1, R2, … for requirements; examples keep document order.

Be concise: one short sentence per requirement, minimal excerpts, and notes
only where they change the interpretation.

OUTPUT CONTRACT — reply with strict JSON only:
{"requirements": [{"id": "R1", "text": "<requirement>", "kind":
"explicit|inferred|ambiguous", "source": {"page": 2, "excerpt": "<verbatim
excerpt or empty>"}}], "examples": [{"input": "<exact input>", "output":
"<exact output>", "page": 2}], "ambiguities": [{"text": "<what is unclear>",
"impact": "<what it limits>"}], "extraction_diagnostics": {"pages_read":
<int>, "requirements_explicit": <int>, "requirements_inferred": <int>,
"requirements_ambiguous": <int>, "notes": "<honest notes>"}}

Example output:
{"requirements":[{"id":"R1","text":"Read integers until EOF; print their sum.","kind":"explicit","source":{"page":1,"excerpt":"print the sum of all integers read"}},{"id":"R2","text":"Print the sum on its own line.","kind":"inferred","source":{"page":null,"excerpt":""}}],"examples":[{"input":"1 2 3","output":"6","page":1}],"ambiguities":[{"text":"Blank lines in input: not addressed.","impact":"Blank-line handling cannot be graded."}],"extraction_diagnostics":{"pages_read":1,"requirements_explicit":1,"requirements_inferred":1,"requirements_ambiguous":1,"notes":""}}
